# 🔐 Projeto Tela de Login com Git

Este projeto foi desenvolvido com o objetivo de praticar conceitos de **desenvolvimento web** e **controle de versão com Git e GitHub**.

---

## 🎯 Objetivo

Criar uma **tela de login com tema escuro**, contendo:

* Validação de campos com JavaScript
* Exibição de mensagens de erro
* Organização do projeto utilizando Git (branches, commits, merge)

---

## 🖥️ Funcionalidades

✔️ Tela de login com design moderno (dark mode)
✔️ Validação de campos obrigatórios
✔️ Mensagens de erro para usuário
✔️ Simulação de login válido
✔️ Controle de versão com Git

---

## 🔑 Regras de validação

* Se usuário ou senha estiver vazio:
  → Exibe: **"Preencha todos os campos!"**

* Se usuário = `adm` e senha = `123`:
  → Exibe: **"Login realizado com sucesso!"**

* Caso contrário:
  → Exibe: **"Usuário ou senha incorretos."**
